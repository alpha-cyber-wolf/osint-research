# OSINT Research

A space for documented methods and learning resources based on publicly available sources.

## Status

This repository is an initial scaffold. Research notes, source-evaluation guides, and educational examples will be added as they are prepared. No personal datasets or case material are published here.

## Responsible research

- Use lawful, publicly available sources and respect their terms.
- Minimize collection and retention of personal information.
- Do not use this repository to target, identify, or expose private individuals.
- Record source links, access dates, assumptions, and uncertainty.
- Clearly distinguish observations from inferences.

## Planned material

- Source reliability and verification checklists
- Public-source research methodology
- Educational examples using non-sensitive material

Do not submit personal information, credentials, client data, or confidential case details in issues or pull requests.

## Contributions

Contributions should explain scope, source provenance, limitations, and privacy considerations.
